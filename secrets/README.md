# Runtime secrets

Create the following files on the deployment host with mode `0600`:

- `openai_api_key`
- `llama_cloud_api_key`
- `postgres_password`
- `restic_password`
- `s3_access_key_id`
- `s3_secret_access_key`

Only this README is tracked. Secret values and generated files in this directory are ignored by Git.
